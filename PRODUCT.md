# Product

## Register

product

## Users

Software engineers working inside a headed desktop coding-agent workflow. They
need dense, predictable controls that stay out of the way while they choose a
model, inspect changes, manage sessions, and act through the keyboard or mouse.

## Product Purpose

Holt is a first-party desktop coding agent with a Rust UI and an in-process Rust
agent loop. It presents one coherent agent, gives users explicit control over
providers and models, and keeps project, transcript, terminal, and change
workflows in one local application.

## Brand Personality

Focused, precise, calm. The interface should feel like a trustworthy native
engineering tool: compact without becoming cryptic, polished without becoming
decorative, and direct about state and capability.

## Anti-references

- Multi-agent launchers that make implementation details look like products.
- Dashboard decoration, nested cards, or animation that competes with the task.
- Hidden state, ambiguous icons, and controls that require guessing.
- Inconsistent desktop affordances or web-shaped UI that feels foreign in a
  native tool.

## Design Principles

1. Keep the coding task primary and chrome quiet.
2. Reveal meaning at the point of need without permanently increasing density.
3. Prefer familiar desktop interactions and predictable state transitions.
4. Make provider, model, and execution state explicit before an action runs.
5. Preserve visual and interaction consistency across light and dark themes.

## Accessibility & Inclusion

Maintain readable contrast in both themes, visible keyboard focus, complete
keyboard navigation for menus and pickers, reduced-motion behavior, and labels
for icon-only controls when their meaning is not immediately obvious.
