# Bundled font notices

Holt embeds the following font software in its desktop binary:

- Geist and Geist Mono, copyright The Geist Project Authors, sourced from
  `vercel/geist-font` release `v1.7.2`. The complete license text supplied
  by the upstream project is included beside this notice.
- IBM Plex Sans (`IBMPlexSans-Regular.ttf`), copyright IBM Corp. SIL Open
  Font License 1.1; sourced from the vendored gpui fork's assets. Used as
  the generic sans-serif fallback when rasterizing SVG text.
- Lilex (`Lilex-Regular.ttf`), copyright The Lilex Project Authors (an IBM
  Plex Mono derivative). SIL Open Font License 1.1; sourced from the
  vendored gpui fork's assets. Used as the generic monospace fallback when
  rasterizing SVG text.

Geist is distributed under the SIL Open Font License 1.1. The complete
license text supplied by the upstream project is included beside this notice.
