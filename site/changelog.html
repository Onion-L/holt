    Fixes

    • Turn review pane scrolls both axes
    • Queued-message edit: overflow, submit guard, and error surface
    • Inline message edit: layout, hover, and chrome polish
  3. 0.1.6 Sep 27, 2026

    Features

    • Self-update from GitHub releases
    • Chat-owned session worktrees persist
    • Compact usage tooltip counts
    • Tree hide control collapses the tree column
    • Landing page ships, auto-deployed to Cloudflare

    Fixes

    • OG and Twitter card images use absolute URLs
  4. 0.1.5 Sep 26, 2026

    Fixes

    • Retry chip styled with the busy accent
    • Dropped the Brave international-access note from provider setup
  5. 0.1.4 Sep 26, 2026

    Features

    • Provider Mode: agents propose providers and API keys mid-chat (/provider)
    • Proposal, key, and choose-provider cards in the transcript
    • Inline $ skill mentions with icon chips
    • Provider model probe and fetch dialog, per-row model names
    • Context overflow compacts and continues the same Turn
    • Overloaded providers retry across Turns and subagents, with retry chips on subagent tabs

    Fixes

    • Mermaid diagrams legible on glass; zoom relative to fit
    • Proposal card re-renders when written; clearer diff and Write feedback
    • Inline edit input stretches to full bubble width
  6. 0.1.3 Sep 23, 2026

    Features

    • /init slash command
    • Chat backdrop frosts once the conversation has content
    • Streaming transcript settles as incremental log lines

    Fixes

    • A panicking run settles the queue instead of welding the chat shut
  7. 0.1.2 Sep 22, 2026

    Features

    • MCP support: stdio and streamable HTTP transports
    • MCP lifecycle, retry, and timeout semantics
    • MCP servers settings page — edit, JSON import, connection probe
    • MCP tools mount as agent tools and are documented in prompts
    • Transient provider errors retry with a live retry chip
    • Usage Breakdown folds its tail into an Others row
    • Optional chat backdrop washed under the conversation
    • DMG window styled with background artwork

    Fixes

    • New-chat mode chip reads the engine’s sticky default
    • MCP rows, dialogs, and probe pills polished — mask-click close, hover states, timeouts
  8. 0.1.1 Sep 21, 2026

    Features

    • Inline message edit gains send and cancel buttons
    • Turn change sets attributed to the tool writes that produced them
    • Slash-command rows show bare names

    Fixes

    • Cancelled providers emit their own abort event
    • Stalled provider streams fail instead of hanging
    • Token compaction gains a B tier
  9. 0.1.0 Sep 20, 2026 first print

    Features

    • First public release — your agent, in plain sight
    • Native macOS coding agent: agent loop, transcript, and review in one window
    • Git surface: branches, checkout diffs in four modes, history, fetch
    • Providers, credentials, and settings pages
    • Skills and slash commands
